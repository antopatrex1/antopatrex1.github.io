# Anto Patrex

Personal website at https://antopatrex1.github.io/.

A warm engineering notebook with a personal introduction, work, career timeline, robotics experiment, writing, and contact links. Plain HTML, CSS, and JavaScript; no runtime dependencies.

## Development

Serve the root directory with any static HTTP server. Run `node build.mjs` to validate local links and create the production files in `dist/`. The existing GitHub Pages configuration publishes the root of `main`.

## Content and imagery

Career roles and dates were updated from [Anto’s LinkedIn profile](https://www.linkedin.com/in/antopatrex/) on September 11, 2026. Personal anecdotes were carried over from the previous public website. Writing links point to Anto’s original LinkedIn posts. The portrait and San Francisco cover image come from his profile. The workshop robot is an original AI-generated editorial illustration, not a product photograph.

The interactive diagram demonstrates two-link planar forward kinematics in arbitrary units. It is an educational visualization, not hardware performance data. Main project descriptions intentionally omit unverified numerical performance claims.

To edit: `index.html` contains the text, `styles.css` the responsive theme, and `script.js` the interactive arm.
